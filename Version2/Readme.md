## Explanation of test cases
The testcases have of mainly of two types
1) Checking the correctness of the simulator
2) Showing some interesting Properties of Caching

There are 4 traces for correctness and they demonstrate the cache hits, read hits, write hits, write back policy and LRU policy being used

We have showed 3 different properties
1) First being Array of Structure vs Structures of Array
2) False Sharing
3) The dependency of miss rate on the parameters like cache size and associativity

All of these testcases were made with simplicity in mind. They are all small testcases so that their correctness verified and outputs observed and related. All of these testcases also demonstrate particular and unique features of caching.
